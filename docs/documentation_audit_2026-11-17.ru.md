## Обнаружено и исправлено в документационной ветке

1. **README:** будущие компиляция, мониторинг, кроссплатформенность и React Flow описывались как действующие функции. Переработан в таблицу реализованного/отложенного; актуализирован стек и команды тестов.

5. **Синтаксис Markdown:** устранены буквальные последовательности `\\n\\n`, испортившие часть переносов строк.
6. **Интерфейс:** документы PR #4/#5/#7/#8 синхронизированы с совместным полем цепей, `TRUE/FALSE/UNKNOWN`, двойным щелчком/F2, отдельными C/R у CNT, восьмибитной группой и сохранением только JSON.
7. **История:** подтверждено, что **PR #6** — слитый выпуск Windows RC, а не отсутствующая веха. Выпуск `v0.5.0-rc.1-hardware` отделён от более позднего `main` после PR #7/#8.

## Оставшиеся риски: документация не заменяет исправление кода

- В исходном `src-tauri/src/network/mod.rs` **по-прежнему находится непроверенный сетевой код** HSES/FTP, хотя действующие Tauri-команды отказа предотвращают использование из текущего UI.
- Полный native parser/writer, проверенные границы System/User Ladder, OEM golden fixtures и реальное scan-time исполнение отсутствуют.
- Сохранение JSON не является строго атомарным; проверка symlink не исключает все filesystem races.
- CSP, зависимости/npm lockfile и воспроизводимость релизов требуют отдельного технического PR.
- Нет подтверждения полного HSES чтения и доставки live-состояний с контроллеров.
- Ручной UI smoke test и реальные файлы роботов оцениваются **отдельно** от CI.

**Рекомендованный следующий технический этап:** golden fixtures с реальными `CIOPRG.LST` и security hardening перед созданием какого-либо нативного экспортера. См. [roadmap.md](roadmap.ru.md).
