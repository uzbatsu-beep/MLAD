## 3. Контракт рабочих компоновок

V5-05 вводит дизайн-систему, V5-06 типизированный layout registry и общую сессию проекта. UI-настройки отдельно от данных проекта. V5-07/08 — рабочий Ladder/Inspector. Остальные компоновки появляются с реальными модулями. Тесты: переключение/перезапуск/сброс, несохранённый черновик, фокус, отсутствующий модуль, устаревший снимок, неверные настройки. UI не меняет права доступа.

## 4. Последующие фазы

После G4 уточнить PR по обратной связи: M17 tri-state → память/шаг → время/TMR/CNT → регистры → сценарии; M18 Watch/trace/events/test с INCONCLUSIVE; M19 отчёты; M20 локальный fleet; M21 опциональный AI. Исследования и парсер параллельно. Это не разрешает online-функции.

## 5. Definition of Done

Каждый PR: scope, позитивные/негативные тесты, регрессии, сохранность источника, явное unknown, применимый CI на финальном SHA, документация RU/EN, ограничения, отдельное согласие на merge. Docs-only CI по существующей схеме; пропуск runtime не равен PASS. GUI smoke и OEM bench независимы. Выпуск, Ruleset и доступ к контроллеру требуют отдельных решений.

### 6.1. Предлагаемые критерии UI QA

- Проверить 1280×800, 1920×1080, масштаб Windows 100/125/150%; не считать эти параметры уже протестированными.
- Проверить клавиатуру, видимый focus, доступные имена, отсутствие цветовой зависимости смысла, контраст текста и элементов.
- Проверить перезапуск, переключение темы/акцента/плотности, повреждённые настройки, восстановление layout, несохранённый draft, обновление source snapshot.
- Предлагаемые сочетания: Ctrl+P — переход, Ctrl+Shift+P — Command Palette, Ctrl+F / Ctrl+Shift+F — поиск, F12 / Shift+F12 — запись/ссылки (несколько записей — выбор), Alt+Left / Alt+Right — история, Ctrl+Tab — вкладки, Ctrl+B / Ctrl+J — панели, F2 — только разрешённый draft, F11 — fullscreen. Проверить конфликты WebView2/Windows перед закреплением.
- Автоматические тесты моделей, IPC и UI; дополнительно визуальный протокол Windows с реальными сценариями пользователя. Производительность — измерения на синтетических и разрешённых приватных данных, не обещание заранее достигнутого FPS/latency.

Это план поставки, не утверждение реализованности. Новые зависимости, точные настройки хранения и детализация подэтапов обосновываются в соответствующих PR. Все merge и релизы по отдельному согласию; native write/online остаются заблокированы.
