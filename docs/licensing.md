# Правовая политика MLAD — GNU GPL-3.0-only

**Дата решения:** 17.11.2026. **Статус:** выбран `GPL-3.0-only`; правообладатель собственных оригинальных материалов — физическое лицо **Фёдор Сергеевич Кочедыков**. Проверка прав на ранее включённые сторонние материалы и соблюдение условий распространения **ещё не завершена**.

## 1. Какая именно лицензия

- **Идентификатор SPDX:** `GPL-3.0-only`.
- **Точный текст:** [../LICENSE](../LICENSE) — GNU General Public License, Version 3, 29 June 2007.
- **Важное различие:** `GPL-3.0-only` разрешает использовать именно версию 3. **Опция «or any later version» не предоставляется**. Для будущего перехода на `GPL-3.0-or-later` понадобится отдельное решение авторов/правообладателей, имеющих такие полномочия.
- **Источники полного текста и правил использования:** [GNU GPLv3](https://www.gnu.org/licenses/gpl-3.0.html), [GNU: How to use GNU licenses](https://www.gnu.org/licenses/gpl-howto.html), [SPDX: GPL-3.0-only](https://spdx.org/licenses/GPL-3.0-only.html).
- **Метаданные:** `package.json` / `src-tauri/Cargo.toml` должны содержать `GPL-3.0-only`.

В частности, при распространении исполняемого MLAD или модифицированных бинарных сборок возникают обязательства по предоставлению соответствующего исходного кода и сохранению необходимых уведомлений согласно GPLv3. Нельзя считать размещение исходников на GitHub автоматическим исполнением **всех** условий каждого способа поставки.

## 2. Что относится и не относится к GPL MLAD

| Объект | Правовой режим |
|---|---|
| Собственный исходный код MLAD, на который авторы имеют права | GPL-3.0-only |
| Собственные изменения, принятые в репозиторий | Должны быть совместимы с GPL-3.0-only |
| Rust/npm библиотеки, WebView2 и системные компоненты | **Сохраняют собственные** лицензии и уведомления |
| Руководства, стандартные чертежи и схемы производителя | Не становятся GPL только из-за цитирования в MLAD |
| Оригинальные/обезличенные `CIOPRG.LST` клиента или робота | Права владельца файла; не открываются автоматически |
| Торговые марки Yaskawa / Motoman, логотипы и товарные обозначения | Не лицензируются GPL MLAD |
| Пользовательские JSON-проекты/сохранённые данные | Не лицензируются автоматически GPL только потому, что созданы в MLAD |

**MLAD не является официальным продуктом Yaskawa, не одобрен производителем и не сертифицирован для управления роботами.** Запреты native writer, HSES и FTP сохраняются независимо от правового статуса.

## 3. Правообладатель и проверка происхождения

**Правообладатель собственных оригинальных частей MLAD:** **Фёдор Сергеевич Кочедыков**, физическое лицо. Уведомление: **© 2026 Фёдор Сергеевич Кочедыков**. Правообладатель определён по решению владельца проекта; имя указано в полном виде на русском языке. Уведомление касается только того материала, на который у указанного лица действительно имеются права.

Предыдущее `authors = ["Antigravity Developer"]` в `Cargo.toml` являлось техническим заполнителем и заменено. Латинская транслитерация **не предполагается**: до подтверждения написания для международной дистрибуции используется полное имя на кириллице.

**Открытые проверки перед следующим бинарным релизом:**

1. Убедиться, что оригинальные части создавались правообладателем с необходимыми правами, с учётом возможных договоров с работодателями/контрагентами.
2. Проверить наличие вкладов других правообладателей и правомерность их включения под GPL-3.0-only.
3. Зафиксировать происхождение и лицензии встроенных иконок, изображений, шаблонов, шрифтов, примеров, заимствованного и сгенерированного кода.
4. Указать отдельные copyright notices для чужих материалов — имя основного правообладателя **не подменяет авторство третьих лиц**.
5. Провести отдельное решение по Tauri `identifier` и миграции Windows-приложения; изменение license/author не означает изменения ID установленной программы.
6. Проверить права на любые демонстрационные/исходные файлы роботов и не публиковать конфиденциальные `CIOPRG.LST`.

**GPL не передаёт права на сторонние материалы и не отменяет обязанность соблюдать их лицензии.** Утверждение правообладателя оригинальных частей не заменяет проверку цепочки прав для всего репозитория.

## 5. Процесс поддержки

- PR на новый код указывает происхождение существенных внешних материалов и лицензии включаемых компонентов.
- В шаблоне PR предусмотреть проверку «нет клиентских `CIOPRG.LST` / секретов / авторских руководств».
- При поступлении запроса об уязвимости использовать будущую `SECURITY.md`; лицензирование и safety — разные вопросы.
- При изменении лицензии или принципов внешней поставки нужен отдельный юридический/организационный review.

**Состояние на 18.11.2026:** GPL-3.0-only, реквизиты правообладателя, PR #11–#12 и релизный ZIP+GPL source pipeline уже есть. **Остаются:** независимая проверка прав, SBOM/third-party notices, точность установочных уведомлений и Windows code signing. Этот документ не является индивидуальным юридическим заключением.
