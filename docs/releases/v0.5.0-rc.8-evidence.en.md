## What changed?

Added the "Static Relationships · Hypotheses Only" panel for the selected typed MOV/ADD/SUB/SHL/SHR string. The panel shows the source/destination positions and the previous row with the same M-register ** only when there are no other executable/unconfirmed constructs between them**. The **not* link itself confirms the execution of an instruction, scan conditions, flags, or actual value transfer.

Detailed entries are limited to the first 1,000 candidates. The source is unchanging, SHA-256 The original is preserved. The actual controller files were not published.

## Verification on Windows

1. Open a copy. CIOPRG.LST Through the system dialogue "Review..."
2. Select the typed line. Check the text and source/purpose categories with the original.
3. If you have a text match hypothesis M-register press "Possible source L...", check the transition to the source.
4. Make sure that after PART, STR/OUT, unknown commands, and END, there are no false connections.
5. Make sure that the calculated values, Carry/Zero/Error or confirmed relays are not displayed.
6. Check for no changes to source bytes, SHA and current local comments.
