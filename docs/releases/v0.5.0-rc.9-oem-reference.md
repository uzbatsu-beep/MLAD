# MLAD rc.9 — справочник MOV/ADD/SUB/SHL/SHR (Windows x64)

**OFFLINE / READ-ONLY — инженерная версия для проверки. Не OEM-симулятор.**

## Изменения

- В панели выбранной типизированной команды MOV/ADD/SUB/SHL/SHR доступен справочник по YRC1000 R12: синтаксис, условия выполнения, значения Carry/Zero/Error, ограничения и спорные граничные случаи.
- Изучены руководства YRC1000 R12 и DX100 Rev.0. DX200 firmware и поведение настоящих контроллеров не проверены.
- Добавлено изолированное Rust-ядро ручных reference-тестов для 16-bit ADD/SUB/MOV/SHL/SHR. Оно НЕ подключено к открываемому CIOPRG.LST и не создаёт фактических значений сигналов.
- При byte=256 и сдвиге n=0/16 неизвестные флаги отмечаются Unresolved вместо предположений.
- Сохранены все возможности rc.8: Native Workspace, IONAME, статические ссылки, Ladder/TMR/CNT, диагностика.

## Приёмка

1. Открыть копию настоящего CIOPRG.LST.
2. Выбрать по очереди MOV, ADD, SUB, SHL, SHR в исходном тексте; для каждой проверить OEM-справку и явные ограничения.
3. Убедиться, что справка не объявляет исполнение реального контроллера подтверждённым, не выводит вычисленные значения реальных регистров.
4. Проверить прежние Ladder, TMR/CNT/GSTR, IONAME и локальные комментарии.
5. Сверить сохранность хэша оригинального файла.

[Разбор команд и план автономной/OEM проверки](../oem_5_opcode_analysis.md).
