# MLAD Native CIO Workspace — Windows preview rc.3

This is an **OFFLINE, read-only engineering preview**, not a native compiler or OEM-equivalent controller product.

## Why this release
The previous release kept the original file in a full-screen overlay and showed the old JSON editor as a first-class tab. This release places the real exported CIOPRG.LST in the **main application working area**. A new three-pane layout replaces the old inspector: file/section navigation (left), source/diagrams (center), diagnostics/search (right).

## How to use
1. Start the Windows 10/11 x64 portable EXE (installed Microsoft WebView2 required), or the NSIS setup (offline WebView2 installer included).
2. The default tab ** Robot program · CIOPRG.LST** opens on startup; paste the path to a **copy** of the controller export, choose the correct DX100/DX200/YRC1000 profile, and press ** Open source **
3. On the left, click PART, END, ALARM or MESSAGE headers to navigate to the original line. PART labels do **not** establish System/User edit permissions.
4. Browse all lines in the center using pages and a direct line number. Select Ladder or advanced-block views to inspect the limited recognized subset; jump back to source via.
5. Search the entire source with ASCII queries of 2–64 characters (up to 100 results). Clicking a result opens its source line. Any source mutation invalidates subsequent page/search operations by SHA-256.
6. On the right, review errors/warnings and copy the JSON diagnostic summary for **private** feedback. The report can contain sensitive addresses; review it before sharing.
7. To use editable experimental JSON, open separate tabs ** Ladder draft** and **TMR · CNT · GSTR/GOUT**. The deprecated project. json editor is now under **Additional → JSON editor v1 (compatibility)**

## Known limitations
- Input uses a local path field rather than a native Windows file selection dialog; this remains a UX task.
- Source view is full and paged, but semantic/diagram previews are intentionally bounded and incomplete.
- Some lines after END (ALARM/MESSAGE) may still be misclassified by the existing syntax analyzer. The section navigator does not claim corrected execution semantics.
- Real CIOPRG exports are **not** included in the public repository or release.
- No edit, native writer, FTP/HSES, online I/O monitoring, robot upload or System/User modification is enabled.
- ZIP executable is unsigned and requires WebView2; the setup includes offline WebView2 prerequisites.
- Every build includes the GPL-3.0 LICENSE and the corresponding version-matched source archive. Verify the asset checksums in SHA256SUMS.txt.
