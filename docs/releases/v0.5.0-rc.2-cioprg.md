# MLAD Bench 0.5.0-rc.2 — Native CIOPRG Read-only Preview

**Experimental Windows x64 / OFFLINE preview.** Built from the unmerged release candidate branch; not a controller-compatible compiler or a production release.

## What's new
- Full original `CIOPRG.LST` text is accessible as 250-line pages, including content beyond the old 600-line preview.
- Jump directly to any line number; displayed line classification and raw byte-span metadata remain read-only.
- Each page reopens the file using existing 16 MiB / 200,000-line bounds and verifies the original SHA-256. If bytes change, the user must reopen the source.
- Review available diagnostics and produce a JSON diagnostic summary in a selectable text field.
- Existing Ladder and Advanced block diagrams remain **partial best-effort previews**, not OEM-verified logic.
- Builds on the merged security PR #13: no compiled unverified HSES/FTP client, and all controller write/monitor commands remain disabled.

## How to test
1. On Windows 10/11 x64, extract the **portable ZIP** and launch `yaskawa-ladder-ide.exe` (requires installed Microsoft WebView2 Runtime), or use the **setup EXE** with offline WebView2 installer.
2. Choose `Просмотр CIOPRG.LST`, enter the **path to a copy** of your file; select its actual controller family (DX100, DX200 or YRC1000), then open it.
3. Record the size, line count, SHA-256 and supported/unknown counts; switch to a page beyond line 600 and test direct jump.
4. Inspect source lines, diagnostics, and recognized Ladder/Advanced preview. Graphical recognition is incomplete; unsupported constructs must remain obvious.
5. Press `Сформировать JSON-отчёт диагностики`, copy its text to a local `.json` file and share it privately for debugging after reviewing sensitive addresses.
6. Compare source SHA-256 externally (`Get-FileHash -Algorithm SHA256`) before and after. They must match.

## Safety and limitations
- No native `CIOPRG.LST` writer or export, controller upload, live I/O, FTP or HSES monitoring.
- No System/User editing authorization or guarantee of controller/firmware equivalence.
- Parser may still misclassify some alarm/message data after `END`. This is specifically a subject of future parser verification; the source text is unchanged.
- The existing semantic preview is limited to a subset of supported constructs; the paged text is complete, **semantic analysis is not**.
- Unsigned preview. Windows SmartScreen might warn. Only download files from this GitHub Release and verify the included SHA-256 list.
- Public repository includes LICENSE and corresponding source archive; do not add private controller exports to GitHub issues.
- Portable EXE requires an installed WebView2 runtime; NSIS setup bundles offline installer.

## Suggested feedback
For each file, report controller/firmware, whether all pages loaded, count of unknown lines, any parsing warnings (ideally line numbers), and discrepancies compared with OEM Ladder Editor. Send actual controller program exports only through an approved private channel.
