# MLAD 0.5.0-rc.5 — Compact Native Workspace / Windows x64 Preview

> **Archived release note — navigation addendum from 18.11.2026.** Below are details of the specific release **rc.5** published earlier; they do not describe the current release. `main`. Now. **Engineering test version. OFFLINE / READ-ONLY / not an OEM-verified Ladder compiler.**

## Requested changes

- Two native source files **CIOPRG.LST** and **IONAME.DAT** are selected from the same compact upper Workspace header, to the right of the native document title.
- Each picker has an `Обзор…` button that opens the **operating system’s native Open File dialog** with an appropriate extension filter. Selected files are loaded immediately. The previous file remains open when the dialog is cancelled.
- The controller family selector stays with CIOPRG.LST. Long paths remain optionally editable as a fallback, with the selected basename shown in the header and the full path on hover.
- The old two full-width file-path rows are removed, restoring vertical space to the editor.
- Ladder and TMR/CNT/GSTR zoom controls (−, +, 100%) and the number of available chains/blocks are located **on the same row as workspace tabs**, contextually by active mode. Zoom states remain independent.
- Header adapts at 1490, 1060 and 700 px to avoid clipped file controls; usability at 1280 × 800 must be verified manually on Windows.
- All previously available read-only CIOPRG source, parser diagnostics, Ladder cards, advanced cards, and local I/O annotations remain.

## Security
- Native file choosing is a **Rust-only Tauri IPC** using `tauri-plugin-dialog` (no JavaScript dialog/save permissions). Only `cioprg` and `ioname` categories are accepted; the selected local path must be absolute, a regular file and within existing 16 MiB/4 MiB bounds.
- Existing read-only parsing commands continue to validate and SHA-256 hash original source bytes.
- Neither `CIOPRG.LST` nor `IONAME.DAT` is modified. Local comments are not controller comments or OEM file edits.
- Native writer, HSES, FTP, upload, live I/O and System/User editing remain disabled.

## Bench acceptance
1. At 1920x1080 and 1280x800 verify both file selectors appear beside the document title and remain operable.
2. Use each ***** button to load real **copies** of CIOPRG.LST and IONAME.DAT; verify cancel does not drop the current document.
3. Check long Cyrillic/ASCII Windows paths and that the correct controller profile is selected.
4. Select Ladder and Advanced tabs; verify no duplicate zoom toolbar appears inside the scrolling diagram view and each mode remembers its own zoom.
5. Compare source SHA-256 with the original before and after; no bytes should change.
