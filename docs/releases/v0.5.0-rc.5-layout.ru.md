# MLAD 0.5.0-rc.5 — Compact Native Workspace / Windows x64 Preview

> **Архивное release note — навигационное дополнение от 18.11.2026.** Ниже сохранены сведения о конкретном релизе **rc.5**, опубликованном ранее; они не описывают текущий `main`. Сейчас PR #1–#21 merged и последняя сборка — [rc.9](https://github.com/uzbatsu-beep/MLAD/releases/tag/v0.5.0-rc.9-oem-reference). [Актуальная матрица функций и рисков](../project_status.ru.md). Релизный tag и архив исходников прошлой версии этим дополнением не изменяются.

** Инженерная тестовая версия. OFFLINE / READ-ONLY / не OEM-верифицированный компилятор лестницы.

## Запрошенные изменения

- Два исходных файла **CIOPRG.LST** и **IONAME.DAT** выбираются из того же компактного верхнего заголовка рабочего пространства справа от нативного заголовка документа.
- Каждый выборщик имеет `Обзор…` кнопка, открывающая диалог Open File** операционной системы с соответствующим фильтром расширения. Выбранные файлы загружаются немедленно. Предыдущий файл остается открытым, когда диалог отменяется.
- Семейство контроллеров остается с CIOPRG.LSTДлинные пути остаются необязательно редактируемыми в качестве запасного варианта, при этом выбранное базовое имя отображается в заголовке и полный путь на наведении.
- Удалены два старых полноразмерных ряда файловых путей, восстанавливающих вертикальное пространство редактора.
- Лестница и элементы управления масштабированием TMR/CNT/GSTR (−, +, 100%) и количество доступных цепочек/блоков расположены ** в той же строке, что и вкладки рабочего пространства**, контекстно в активном режиме. Страны Зум остаются независимыми.
- Заголовок адаптируется на 1490, 1060 и 700 px, чтобы избежать обрезанных элементов управления файлами; удобство использования на 1280 × 800 должно быть проверено вручную в Windows.
- Все ранее доступные только для чтения источники CIOPRG, парсерная диагностика, карты лестницы, расширенные карты и локальные аннотации ввода / вывода остаются.

## Security
- Нативный выбор файла - это ** IPC Tauri только для рустовых файлов ** `tauri-plugin-dialog` (нет диалогов JavaScript/сохранить разрешения). Только `cioprg` and `ioname` Категории принимаются; выбранный локальный путь должен быть абсолютным, обычным файлом и в пределах существующих 16 MiB/4 MiB границ.
- Существующие команды анализа только для чтения продолжают проверять и SHA-256 хеш исходных байтов.
- Neither `CIOPRG.LST` nor `IONAME.DAT` изменены. Локальные комментарии не являются комментариями контроллера или редактированием OEM-файлов.
- Родной писатель, HSES, FTPЗагрузка, ввод в эксплуатацию и редактирование системы / пользователя остаются отключенными.

## Принятие скамейки
1. В 1920x1080 и 1280x800 проверьте, что оба селектора файлов появляются рядом с заголовком документа и остаются работоспособными.
2. Use each **Обзор…** button to load real **copies** of CIOPRG.LST and IONAME.DATПроверить отмену не отбрасывает действующий документ.
3. Длинная кириллица / ASCII Пути Windows и выбор правильного профиля контроллера.
4. Выберите вкладки «Лестница» и «Расширенный»; проверьте, что внутри диаграммы прокрутки не появляется дублирующая панель инструментов зума, и каждый режим запоминает свой собственный зум.
5. Сравнить источник SHA-256 с оригиналом до и после; никакие байты не должны меняться.
