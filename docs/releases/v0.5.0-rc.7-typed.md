**Windows x64 / OFFLINE / READ-ONLY / diagnostic engineering preview.**

## What is new

The native CIOPRG reader can structurally identify `MOV`, `ADD`, `SUB`, `SHL` and `SHR` with explicit operand kinds: M-register, decimal constant, byte-group relay and word-group relay. The source panel keeps the original line unchanged. The right-hand panel shows the selected candidate's operands and shape status. Counts for these candidates are separated from the previously recognized boolean instructions and unknown records.

## Safety

- **Typing is not execution.** `semantics_verified=false` for every typed candidate. The semantic analyzer deliberately treats these commands as **barriers** and does not build reconstructed Ladder rungs from them.
- DX100 grammar equivalence is not established. Vendor firmware and application-specific execution/flags, target permissions and full System/User boundaries are not certified.
- CIOPRG and IONAME files are read-only; there is no native writer, save dialog to controller, FTP/HSES or robot deployment.
- Real controller exports are private and excluded from source archives.

## Suggested Windows validation

1. Launch rc.7 and select a copy of the robot's CIOPRG.LST; verify all original lines and hash remain unchanged.
2. Check the source status: **typed** vs **confirmed boolean** vs **unknown**, and per-opcode `MOV`, `ADD`, `SUB`, `SHL`, `SHR` counts.
3. Click typed lines and verify operands have the expected lexical categories; compare their spelling against the original bytes.
4. Verify unsupported instructions still remain opaque and typed operations do **not** create false rungs or interpreted live I/O values.
5. Check invalid forms are diagnosed as such without changing source.
6. Report model, controller generation, firmware, export provenance and private differences; do not publish native programs.

## Build and licensing

Windows x64 GitHub Actions builds a portable ZIP, NSIS installer, GPL-3.0-only source archive and SHA256SUMS after npm ci, TypeScript and Rust tests. The portable EXE requires WebView2 Runtime; NSIS includes offline WebView2 installer.
