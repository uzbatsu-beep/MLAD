# MLAD Native CIO Workspace — предварительный просмотр Windows rc.3

> **Архивное release note — навигационное дополнение от 18.11.2026.** Ниже сохранены сведения о конкретном релизе **rc.3**, опубликованном ранее; они не описывают текущий `main`. Сейчас PR #1–#21 merged и последняя сборка — [rc.9](https://github.com/uzbatsu-beep/MLAD/releases/tag/v0.5.0-rc.9-oem-reference). [Актуальная матрица функций и рисков](../project_status.ru.md). Релизный tag и архив исходников прошлой версии этим дополнением не изменяются.

Это **OFFLINE, только для чтения предварительный просмотр **, а не нативный компилятор или OEM-эквивалентный продукт контроллера.

## Почему этот релиз
Предыдущий релиз сохранил оригинальный файл в полноэкранном наложении и показал старый редактор JSON в качестве вкладки первого класса. Этот выпуск помещает реальный экспортируемый CIOPRG.LST ** Основная рабочая область **. Новая трехпанельная компоновка заменяет старый инспектор: файловая/секционная навигация (слева), исходные/диаграммы (в центре), диагностика/поиск (справа).

## Как использовать
1. Запустите Windows 10/11 x64 Portable EXE (установлена Microsoft) WebView2 требуется) или установка NSIS (оффлайн WebView2 Установщик включен).
2. The default tab **Программа робота · CIOPRG.LST** открывается при запуске; вставьте путь к **копии** экспорта контроллера, выберите правильный DX100/DX200/YRC1000 profile, and press **Открыть исходник**.
3. Слева нажмите заголовки PART, END, ALARM или MESSAGE, чтобы перейти к исходной строке. Частичные ярлыки **не** устанавливают права на редактирование системы/пользователя.
4. Browse all lines in the center using pages and a direct line number. Select Ladder or advanced-block views to inspect the limited recognized subset; jump back to source via **К исходнику**.
5. Поиск по всему источнику с помощью ASCII запросов 2-64 символов (до 100 результатов). Нажатие на результат открывает исходную линию. Любая мутация источника аннулирует последующие операции поиска страницы SHA-256.
6. Справа просмотрите ошибки/предупреждения и скопируйте диагностическое резюме JSON для обратной связи **private**. Отчет может содержать конфиденциальные адреса; просмотрите его, прежде чем делиться.
7. To use editable experimental JSON, open separate tabs **Черновик Ladder** and **TMR · CNT · GSTR/GOUT**. The deprecated project.json editor is now under **Дополнительно → Редактор JSON v1 (совместимость)**.

## Известные ограничения
- Ввод использует локальное поле пути, а не нативный диалог выбора файлов Windows; это остается задачей UX.
- Просмотр исходного текста является полным и постраничным, но предварительные просмотры семантических/диаграмм намеренно ограничены и неполны.
- Некоторые линии после END (ALARM/MESSAGE) все еще могут быть неправильно классифицированы существующим синтаксическим анализатором. Навигатор раздела не претендует на исправленную семантику исполнения.
- Реальный экспорт CIOPRG не включен в публичное хранилище или выпуск.
- Нет монтажа, родной писатель, FTP/HSESОнлайн-мониторинг ввода/вывода, загрузка робота или модификация системы/пользователя.
- Исполняемый ZIP не подписан и требует WebView2; настройка включает офлайн WebView2 prerequisites.
- Каждая сборка включает в себя GPL-3.0 LICENSE и соответствующий архив источников. Проверить контрольные суммы активов в SHA256SUMS.txt.
