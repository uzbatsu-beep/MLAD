> **PRE-RELEASE · BENCH / OFFLINE Only · NO CONTROLLER WRITES**

Этот пакет содержит инженерный интерфейс MLAD для подготовки Yaskawa Concurrent I/ О!
Оценка скамейки лестниц на **DX100, DX200 and YRC1000**.

## Contents
- Только для чтения без потерь импорт / проверка существующего `CIOPRG.LST`: SHA-256 байты источника, диапазоны источников, диагностика разбора, типизированная реле / проверка памяти.
- Семантическая экспрессия AST, дисплей лестницы SVG в электрическом стиле и перекрестные ссылки.
- Independent `*.graph.json` редактор (AND/OR, NO/NC, edit/undo/redo).
- Independent `*.advanced.json` расширенный редактор блоков для **TMR**, **CNT** (два независимых ввода C/R), **GSTR + GOUT** (один байт, спаренный).
- Явная офлайн-модель таймера на 100 мс, модель CNT с приоритетом «повышение/перезагрузка», макет 8-битной групповой копии.
- Инвентарь шаблонов инструкций только для чтения для оригинальных программ; неизвестные шаблоны остаются непрозрачными.
- Sample `*.advanced.json` (только синтетический; никогда не импортируйте в контроллер), матрица валидации скамейки, шаблон быстрого запуска оператора и шаблон журнала результатов.

## Используйте ограничения

**Нет замены редактора Yaskawa Ladder, проверенного компилятора CIOPRG, HSES монитор, FTP Загрузчик, контроллер движения/серво или проверенное устройство функциональной безопасности. Диагностика зеленого редактора не является одобрением аппаратного обеспечения. Родной отредактированный `.LST` экспорт и оба FTP загружать и HSES Сетевой мониторинг отключен бэкэндом.

Любое фактическое программирование контроллера или функциональные упражнения ввода-вывода должны использовать **OEM-утвержденный редактор лестницы **, резервный немодифицированный `CIOPRG.LST`, официальное разрешение на проведение испытаний, безопасные сигналы без движения и защищенная испытательная ячейка. Никогда не меняйте системную лестницу с помощью этого приложения.

## Первое испытание дыма (без контроллера)

1. проверить SHA-256 Загруженный установщик или портативный ZIP против `ARTIFACTS_SHA256.txt`.
2. Начните MLAD с **без подключения сети роботов**. Проверьте желтый баннер **STAND / OFFLINE** и отображаемую версию.
3. Выберите **TMR · CNT · GSTR/GOUT**, добавьте каждый тип и проверьте этикетки портов: TMR start; CNT **C** и **R**; GRP GSTR и GOUT байт-адреса.
4. Введите предустановленный TMR M010 100: 100 ручных шагов + 100 мс должны достичь Q=1 после 10 смоделированного времени. Запуск сброса и подтверждение перезагрузки. Это смоделированное логическое время, а не настенные часы Windows.
5. Введите предустановленный CNT M020 3, переключите C OFF→ON три раза, проверьте отсутствие пересчета при удерживании, затем включите R и проверьте немедленный сброс.
6. Введите GSTR #20010, GOUT #70030. Перемешайте известный байт (например, 0x55) и проверьте идентичный выходной байт.
7. Сохранить и вновь открыть **`*.advanced.json`** Импорт утвержденного клиентом источника `CIOPRG.LST` only through **Просмотр CIOPRG.LST**, только для чтения.
8. Убедитесь, что **FTP / HSES** Операции отключены. ** Не пытайтесь загрузить расширенный JSON. CIOPRG.LST.**

Для тестирования реального устройства, сначала `docs/advanced_hardware_test_matrix.md` и записывать результаты в предоставленный шаблон CSV. Ни один из этих случаев с реальными устройствами не был выполнен этим конвейером выпуска.

## Строить и качественные ворота

Построен с помощью Tauri v2, Rust, Node 22, React/TypeScript на **GitHub Actions Windows x64**.
Рабочий процесс релиза открывает публикацию по:
- Rust `cargo test --locked`;
- фронтенд-граф-модель и расширенные блок-тесты;
- TypeScript check и Vite production build;
- Windows NSIS bundling;
- доступный исполняемый / установщик и SHA-256 manifest.

CI не может утверждать о реальном взаимодействии с графическим интерфейсом Windows или выполнении аппаратного обеспечения робота.
Используйте проверенную версию источника / SHA на странице предварительного выпуска GitHub в качестве ключа отслеживания.
