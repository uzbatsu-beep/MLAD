Экспериментальная Windows x64 / OFFLINE preview. Построенный из неслитого ветви-кандидата выпуска; не совместимый с контроллером компилятор или производственный выпуск.

## Что нового
- Полный оригинал `CIOPRG.LST` Текст доступен в виде 250-строчных страниц, включая контент за пределами старого 600-строчного предварительного просмотра.
- Перейдите непосредственно к любому номеру строки; отображаемая классификация строк и метаданные байт-спана остаются только для чтения.
- Каждая страница заново открывает файл, используя существующие 16 МиБ / 200 000 строк и проверяет оригинал. SHA-256Если байты меняются, пользователь должен повторно открыть источник.
- Просмотрите доступную диагностику и создайте диагностическое резюме JSON в выбираемом текстовом поле.
- Существующие блок-схемы Ladder и Advanced остаются ** частично лучшими предварительными просмотрами**, а не проверенной OEM-логикой.
- Строительство объединенной безопасности PR #13Нет составленных непроверенных HSES/FTP клиент, и все команды записи / мониторинга контроллера остаются отключенными.

## Как проверить
1. В Windows 10/11 x64 извлеките **portable ZIP** и запустите `yaskawa-ladder-ide.exe` (необходимо установить Microsoft) WebView2 Runtime или используйте **setup EXE** с оффлайн WebView2 installer.
2. Choose `Просмотр CIOPRG.LST`, введите ** путь к копии ** вашего файла; выберите его фактическое семейство контроллеровDX100, DX200 or YRC1000Затем откройте его.
3. Запишите размер, количество строк, SHA-256 Поддерживаемый/неизвестный счет; перейдите на страницу за пределами 600 строки и проверьте прямой прыжок.
4. Проверьте исходные линии, диагностику и распознанный предварительный просмотр. Графическое распознавание неполно; неподдерживаемые конструкции должны оставаться очевидными.
5. Press `Сформировать JSON-отчёт диагностики`скопировать его текст в местный `.json` файл и поделиться им в частном порядке для отладки после просмотра конфиденциальных адресов.
6. Сравнить источник SHA-256 снаружи ()`Get-FileHash -Algorithm SHA256`) до и после. Они должны совпадать.

## Безопасность и ограничения
- Уроженец `CIOPRG.LST` автор или экспорт, загрузка контроллера, live I/O, FTP or HSES monitoring.
- Нет авторизации на редактирование системы/пользователя или гарантии эквивалентности контроллера/программного обеспечения.
- Parser может по-прежнему неправильно классифицировать некоторые данные о тревоге/сообщении `END`Это конкретно предмет будущей проверки парсера; исходный текст неизменен.
- Существующий семантический предварительный просмотр ограничен подмножеством поддерживаемых конструкций; размещенный на странице текст завершен, ** семантический анализ не**.
- Неподписанный предварительный просмотр. Windows SmartScreen может предупредить Загружайте только файлы из этого выпуска GitHub и проверяйте включенные SHA-256 list.
- Публичное хранилище включает в себя LICENSE и соответствующий архив источников; не добавляйте экспорт частных контроллеров в выпуски GitHub.
- Портативный EXE требует установки WebView2 Runtime; NSIS setup bundles offline installer.
