## Terminology contract / Терминологический контракт

| In source / В исходнике | English rendering | Русский эквивалент | Interpretation / Толкование |
| --- | --- | --- | --- |
| `read-only` | read-only | только чтение | No modification of the original bytes / Оригинал не изменяется |
| `BLOCKED` | prohibited / unavailable | запрещено / недоступно | Not supported or authorized / Не реализовано или не разрешено |
| `NOT RUN` | not performed | не проводилось | **Never** translate as passed, failed, or ignored / Не равно PASS или FAIL |
| `ManualDerived` | manual-derived | выведено из руководства | Not tested as an OEM scan / Не равно испытанию контроллера |
| `SyntheticTested` | tested on synthetic data | проверено на синтетических данных | Not a real robot fixture / Не доказательство совместимости с реальным роботом |
| `File ID` | file identity | идентичность файла | Not a transaction or race-free operation / Не атомарная транзакция |
| `staged write` | staged file write | запись через временный файл | Backup + target is not one atomic commit / Пара backup и target не атомарна |
| `semantic rung` | ladder rung / circuit | цепь Ladder / логическая цепь | Not a physical motion or wire energized status / Не физический сигнал |
| `source span` | source byte/line range | диапазон байтов/строк источника | Must map to unchanged original / Привязан к неизменному исходнику |
| `controller profile` | controller family profile | профиль семейства контроллера | DX100/DX200/YRC1000 differences are not silently merged / Семейства различаются |

## Review gates / Критерии проверки

1. Match each localized file to its source and preserve all fenced code, URLs, command invocations, paths and exact technical identifiers. / Сверить каждый перевод с исходником, сохранить код, адреса, команды и ссылки.
2. Verify safety clauses, CIOPRG/IONAME read-only, HSES/FTP/native writer BLOCKED. / Проверить предупреждения о безопасности и запреты на запись/подключение.
3. Independently review terminology and examples for DX100/DX200/YRC1000. / Проверить терминологию и примеры по руководствам Yaskawa.
4. Until human review, translated files are drafts, not an independently validated OEM source. / До рецензирования переводы являются черновиками, а не подтверждённой OEM документацией.

5. Run `python3 scripts/i18n_verify.py` and `python3 scripts/i18n_semantic_guard.py` in CI. This checks structure, unchanged code fences, key identifiers, language navigation and critical release-status negations; it does **not** certify translation quality. / Выполнять указанные проверки в CI; они не заменяют ручную редактуру.
6. During later editorial passes, update the review register only after comparing **every semantic section, table cell, negative statement and warning** with the original. Do not mark a full document as `EngineeringVerified` after glossary-only substitutions. / Не присваивать статус полной верификации по одной проверке терминов.
