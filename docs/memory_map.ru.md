# Memory map — архив предварительной карты адресов

> **Архивный указатель (сверка 18.11.2026):** этот файл сохраняется для ссылок; не использовать его как действующую спецификацию. PR #1–#21 слиты, последний Windows релиз — rc.9. [Текущий статус](project_status.ru.md).

** Не используйте более ранние версии этого файла в качестве источника действительности адреса или разрешения на запись.

Оригинальный прототип MLAD изменил классы CIO (например, `1xxxx` Внешний вход и `2xxxx` Внешний выход. Для верифицированных таблиц контроллера используйте **[Типовая модель памяти — DX100, DX200, YRC1000](typed_memory_model.ru.md)**.

Реализация этих диапазонов, типизированных бит/байт/слово/адреса регистров и тестов живет в `src-tauri/src/compiler/memory.rs`.

## Ключевые правила

- Установите явный `ControllerFamily` для валидации производства: `DX100`, `DX200`, `YRC1000`.
- Нотификация битового адреса реле: `#XXXXX` с конечной цифрой `0..7`; канал `number/10`.
- Диапазоны ввода/вывода сети и псевдовхода существенно различаются между поколениями.
- Таблица адресного класса не дает разрешения на запись реальному роботу.
- M-регистрация 16-битная `M000..M999`; применяются ограничения на роль, владение и обучение.
- Прочитай [CIOPRG.LST базовый уровень спецификации](cioprg_lst_spec.ru.md) Прежде чем попробовать компилятор.

Источник индекса: [Исходный реестр](source_registry.ru.md).

## Статус UI после PR #8

В новых вкладках MLAD оператор выбирает `DX100`, `DX200` или `YRC1000`; Rust использует профиль в `memory.rs` и отдельных валидаторах JSON / read-only Inspector. Фронтенд inline-ввода проверяет только **формат**, после чего Rust проверяет типы и диапазоны. Legacy JSON workflow сохраняет совместимые ограничения.

Никакая успешная проверка диапазона не означает разрешённую аппаратную запись. См. [typed_memory_model.md](typed_memory_model.ru.md), [architecture.md](architecture.ru.md) и [документацию](README.ru.md).
