# MLAD — IONAME.DAT и комментарии к адресам и цепям (экспериментально)

**Статус на 18.11.2026:** функциональность PR #16 **объединена с `main`**. В Native Workspace доступны read-only импорт `IONAME.DAT`, локальные комментарии и **ручные** ассоциации. Нативного writer и подтверждённого автоматического сопоставления IONAME→#XXXXX **нет**. См. [сверенный статус](project_status.ru.md).

## Источники и неизвестные части формата

Yaskawa определяет `IONAME.DAT` как данные имён I/O, **отличные** от `CIOPRG.LST`. В опубликованных примерах имеется заголовок `/IONAME`, за которым следуют именованные разделы `//IN`, `//OUT` и строки, содержащие **по четыре имени через запятую**. MLAD читает эти записи в ограниченную таблицу **только для просмотра** и вычисляет SHA-256 оригинала. Неизвестные варианты форматирования диагностируются, но **не домысливаются**.

Источники:
- Yaskawa: https://knowledge.motoman.com/hc/en-us/articles/4405166620567-Alias-Function-for-Variables-and-I-O
- Yaskawa: https://knowledge.motoman.com/hc/en-us/articles/25864549058327-Robot-Pendant-Concurrent-I-O-Graphical-Ladder-with-Comments
- Пример структуры: https://dramat.eu/doc/yaskawa_basic.html

**Не подтверждено:** точное устройство файла для конкретных firmware YRC1000 и соответствие позиций разделов IONAME адресам Concurrent I/O `#XXXXX`. Позиционная таблица из четырёх колонок **не является** подтверждённой адресной картой реле. До автоматического сопоставления необходим подлинный образец с доказательствами.

## Разделение данных

- `CIOPRG.LST`: неизменяемая нативная программа, **только чтение**, побайтовый SHA-256.
- `IONAME.DAT`: неизменяемые нативные имена, **только чтение**, побайтовый SHA-256. Метки показываются для справки, не предназначены для native export.
- Комментарии MLAD: локальные пользовательские аннотации (`rungs`, `addresses`, `ioname`), привязанные к SHA-256 `CIOPRG.LST` и, для конкретных имён, к SHA-256 IONAME и **физической строке/позиции**. LocalStorage переживает обычные переключения вкладок и перезапуск приложения, но **не гарантирует резервного копирования**.
- Двойной щелчок меняет **только локальную аннотацию**. Очистка данных или смена профиля приложения может удалить комментарии. Импорт/экспорт sidecar JSON и проверенный native IONAME writer требуют отдельного проектирования, испытаний и явного согласования.

## Проверки безопасности

1. Размер `IONAME.DAT` ограничен **4 MiB**, `CIOPRG.LST` — **16 MiB**; symlink для IONAME отклоняется.
2. Просмотр снимка **никогда** не записывает нативную программу или файл имён.
3. `relay_mapping_verified = false` и `native_write_allowed = false` — постоянные признаки текущего режима.
4. Ручное сопоставление метки IONAME с `#XXXXX` или `Mxxx` влияет **только на отображение**.
5. Список Ladder показывает доступные `SemanticPreview` цепи и явно сообщает, если результат обрезан.
6. Никаких HSES/FTP, физического I/O, преобразования native source или прав на изменение System/User не предоставляется.
