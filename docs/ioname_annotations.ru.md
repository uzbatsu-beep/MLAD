## Доказательства и неизвестные

Яскава идентифицирует `IONAME.DAT` I/O данные, отличающиеся от `CIOPRG.LST`Опубликованные примеры используют а `/IONAME` заголовок с последующими названными разделами, такими как `//IN`, `//OUT` и строки данных с ** четырьмя именами, разделенными запятыми**. Эта реализация считывает эти записи в ограниченную таблицу только для отображения с оригиналом. SHA-256Другие макеты диагностируются, не догадываются.

Таблица с позиционным названием из четырех колонок не должна быть представлена в качестве проверенной таблицы адресов ретрансляторов. Подлинный образец требуется перед любой автоматической картографией.

## Разделение данных

- `CIOPRG.LST`: неизменяемая нативная программа, только чтение, точный байт SHA-256.
- `IONAME.DAT`: неизменяемые данные нативного имени, только для чтения, точный байт SHA-256Обнаруженные этикетки предназначены для человеческих ссылок, а не для местного экспорта.
- Комментарии MLAD: аннотации локальных пользователей`rungs`, `addresses`, `ioname`) включительно `CIOPRG.LST` SHA-256 и, для отдельных записей IONAME, IONAME SHA-256 Физическая исходная линия/слот. LocalStorage сохраняется через обычные переключатели вкладок и перезагрузки приложений, но ** не ** гарантированное резервное копирование.
- Double-click редактирует только локальную аннотацию. Очистить или изменить профиль приложения может удалить данные. Импорт / экспорт Sidecar JSON и проверенный автор IONAME требуют отдельного дизайна / тестирования и явного одобрения.

## Проверка безопасности

1. Файлы ограничены 4 МБ для IONAME и 16 МБ для CIOPRG, отклоняя симлинки для IONAME.
2. Снимок только для просмотра никогда не пишет оригинальную программу или файл имени.
3. Картографирование этикеток всегда `relay_mapping_verified = false`и `native_write_allowed = false`.
4. Ручная ассоциация этикетки IONAME `#XXXXX` or `Mxxx` Это касается только локального дисплея.
5. Полный список лестниц ограничен всеми этапами SemanticPreview с явным предупреждением об усечении результатов.
6. No HSES/FTP, активируется ввод/вывод устройства, перевод источника или авторизация системы/пользователя.
