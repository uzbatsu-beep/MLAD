# Спецификация регистров и адресов роботов Motoman (Concurrent I/O)

Внутренний ПЛК роботов Yaskawa Motoman (серий DX100, DX200, YRC1000, YRC1000micro) использует фиксированную пятизначную десятичную систему адресации для битовых операндов (реле) и отдельный пул для числовых регистров (M-регистры). 

Данная спецификация верифицирована по официальным стандартам Yaskawa: **RE-CKI-A469**, **HW1483921**, **MRS55130** и руководству **MotoSim EG-VRC** (раздел 5.2 и глава 7).

---

## 1. Битовые операнды (Relay Map)

Каждый адрес представляет собой один бит (флаг). Архитектура делит их на функциональные группы:

| Диапазон адресов | Тип сигналов | Описание | Доступ из Ladder |
| :--- | :--- | :--- | :--- |
| **`10010` – `15127`** | External Inputs | Физические входы от внешнего оборудования (датчики, контроллеры, конвейеры). | Только чтение (`STR`, `AND`, `OR`) |
| **`20010` – `25127`** | External Outputs | Физические выходы на исполнительные механизмы и внешние системы. | Чтение и запись (`OUT`, `SET`, `RST`) |
| **`30010` – `37047`** | Robot Inputs | Системные статусы манипулятора и контроллера (робот в домашней точке, ошибка, режим Servo ON). | Только чтение |
| **`40010` – `42047`** | Robot Outputs | Системные команды управления роботом (запуск программы INFORM, сброс ошибок, удержание паузы). | Чтение и запись |
| **`50010` – `55127`** | Interface Inputs | Внутренние сигналы обмена данными между логикой ПЛК и управляющей программой INFORM. | Только чтение |
| **`60010` – `65127`** | Interface Outputs | Сигналы, передаваемые из ПЛК в программу INFORM (например, флаги завершения технологического цикла). | Чтение и запись |
| **`70010` – `79997`** | Auxiliary Relays | Вспомогательные пользовательские реле для построения промежуточной логики (флаги, триггеры). | Чтение и запись |
| **`80010` – `85127`** | Control Status | Специальные системные регистры состояния оборудования, сетевых интерфейсов и контроллера. | Только чтение |
| **`87010` – `87207`** | Pseudo Input | Псевдо-входы (симулируемые системные сигналы для отладки и эмуляции внешних датчиков). | Только чтение / системное управление |

### Важное правило адресации бит:
Адрес состоит из **номера байта** (первые 4 цифры) и **номера бита** (последняя цифра от 0 до 7). 
*Пример:* Адрес `10015` означает: 1001-й байт внешних входов, 5-й бит (младший бит — 0, старший — 7).

## 2. Регистры памяти (M-Registers)

Для хранения целочисленных данных (счетчики, координаты, режимы работы, технологические параметры) используются 16-битные регистры общего назначения.

* **Диапазон:** `M000` – `M999` (в современных контроллерах YRC1000 пул расширен до `M3999`).
* **Разрядность:** 16 бит (2 байта) со знаком или без знака.
* **Использование в Ladder:** Могут передаваться в качестве аргументов в функциональные блоки: копирование данных (`MOV`), арифметические операции (`ADD`, `SUB`), блоки сравнения (`EQU`, `NEQ`, `GT`, `LT`) и таймеры/счетчики (`TMR`, `CNT`) для динамического задания уставок.

## 3. Правила валидации для компилятора (Rust Backend)

При разборе схемы или файла `.LST` парсер на Rust проверяет соблюдение следующих ограничений:

1. **Запрет записи в Read-Only диапазоны:** Любая попытка использовать адреса из серий `1xxxx`, `3xxxx`, `5xxxx`, `8xxxx` (включая `87010`–`87207`) в инструкциях записи (`OUT`, `SET`, `RST`) вызывает ошибку компиляции (`ReadOnlyAddress`).
2. **Проверка индекса бита:** Последний знак в пятизначном адресе битового реле строго должен находиться в диапазоне от `0` до `7`. Адреса вроде `70018` или `10029` являются синтаксической ошибкой (`InvalidBitIndex`).
3. **Контроль Double Coil (Двойная катушка):** Компилятор выдает предупреждение или ошибку, если один и тот же адрес из серий `2xxxx`, `4xxxx`, `6xxxx` или `7xxxx` назначен в качестве катушки `OUT` в нескольких цепях программы, так как это приводит к гонке сигналов в цикле ПЛК.
